# Gym ChatBOAT

An interactive chatbot designed to assist users with gym-related questions, fitness information, and workout guidance.

## Overview

**Gym ChatBOAT** is a chatbot project focused on making gym and fitness information more accessible through conversational interaction. It aims to help users explore fitness-related topics and receive relevant information through a simple chat-based interface.

## Features

- Conversational interaction for gym-related queries.
- Fitness and workout information assistance.
- User-friendly chatbot experience.
- Designed to make fitness information easier to access.
